About AshiPad

AshiPad is a simple, lightweight rich-text editor with minimal RTF output. Draft visually or edit the source directly — no distractions, just writing.

How to Use

  • Use the Write tab to compose visually with formatting
  • Switch to the RTF source tab to edit the raw RTF code
  • Click the ＋ button to start a new document
  • Use the About button to learn more

Keyboard Shortcuts

  • Ctrl+B — Bold
  • Ctrl+I — Italic
  • Ctrl+U — Underline
  • Ctrl+Shift+S — Strikethrough
