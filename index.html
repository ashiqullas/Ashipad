About AshiPad

AshiPad is a premium, lightweight rich-text editor with minimal RTF output. Draft visually or edit the source directly — no distractions, just writing.

Features

  • Local Auto-save functionality
  • Dark Mode support
  • Essential rich text formatting

Keyboard Shortcuts

  • Ctrl+B — Bold
  • Ctrl+I — Italic
  • Ctrl+U — Underline

Coded by Ashiq Ullas. Upgraded with modern aesthetics.
