# AshiPad

![AshiPad Demo Video](assets/demo.webp)

A premium, lightweight rich-text editor built for focus and speed. AshiPad generates minimal, raw RTF output and saves your work locally in your browser.

## Features

- **Beautiful Modern UI**: Enjoy a clean, distraction-free writing environment with glassmorphism and smooth animations.
- **Dark Mode Support**: Write comfortably in low-light environments with a deep OLED-black dark mode.
- **Minimal RTF Output**: View and copy raw, inline RTF tags directly, without unnecessary document envelopes.
- **Local Auto-save**: Everything you type is automatically saved to your browser's local storage. No servers, no accounts, no data leaves your device.
- **Privacy First**: AshiPad contains no tracking, no analytics, and no external API calls. Your words belong to you.

## Getting Started

Since AshiPad is a purely client-side application, there is no build step or server required!

1. Clone or download this repository.
2. Open `index.html` in your favorite modern web browser.
3. Start writing!

## Shortcuts

- **Ctrl/Cmd + B** — Bold
- **Ctrl/Cmd + I** — Italic
- **Ctrl/Cmd + U** — Underline
